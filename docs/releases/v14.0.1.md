# Zotero PaperFlow 14.0.1

Release Date: 2026-11-04
Compatibility: Zotero 10.0 - 12.* (Gecko 153+ Web Components)

## Bug Fixes & Mathematical Alignment Refinement (v14.0.1)

- **彻底消除操作按钮遮盖与文字挤压重叠 (Fix Action Button Squashing & Text Masking)**：
  - 解绑全局 `.btn-icon` 固定 32px 宽度约束，定制专有 `.btn-review-action` 弹性药丸按钮；
  - 声明 `width: auto !important; min-width: max-content; padding: 0 10px; white-space: nowrap;`，完美容纳图文与不同语种文字，杜绝遮盖掩盖；
  - 危险删除按钮应用独立 `.btn-review-delete` 浅红预警样式（`#fee2e2` / `#b91c1c`），视觉层级鲜明。
- **补全国际化双语字典 (Complete i18n Dictionary)**：
  - 补齐 `reviewerCommentTitle`（审稿人原始意见 / Reviewer Comment）、`statusFieldLabel`（状态 / Status）、`moveUpShort`（上移 / Up）、`moveDownShort`（下移 / Down）、`copyItemShort`（复制问答 / Copy Item）；
  - `review-matrix.js` 内置 `resolveText()` 防御性双语降级机制，任何异常场景下绝不直接暴露未翻译英文标识符。
- **审稿人前缀防折行治理 (Prevent Reviewer Prefix Line Break)**：
  - 为 `.review-meta-item`、`.review-row-reviewer-box` 与 `.review-field-prefix-label` 声明 `white-space: nowrap !important; flex-shrink: 0 !important;`，彻底根除「审稿」与「人:」意外折行。
- **三层结构双列严格工整对称对齐 (Strict 3-Tier Grid Alignment)**：
  - 移除响应式媒体查询中对 `.submission-edit-review-row` 的错误 `grid-template-columns: 1fr` 覆盖；
  - 强制锁定 Tier 1 通栏顶栏、Tier 2 对称双列（左「审稿人原始意见」vs 右「作者学术答复」）、Tier 3 通栏修订说明与位置栏，并在 DOM 与 CSS 层面实现自愈式抗缓存强固。
