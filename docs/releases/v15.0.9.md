# Zotero PaperFlow 15.0.9

TypeScript modernization and intermediate draft migration:
- Migrate core bridge, cloud sync network provider (WebDAV & GitHub REST API), atomic storage engine, conflict recovery matrix, preferences controller, and UI platform adapter to TypeScript modules under `src/modules/`.
- Enhance read-only guard in `syncManuscriptToChildNote` to prevent modifying deleted or read-only note items.
- Modernize clipboard helper in `item-pane.ts` with asynchronous `navigator.clipboard` and safe fallback.
- Integrate chunked UTF-8 base64 encoding in `cloud-sync.ts` replacing legacy `unescape`.
- Add defensive null-safety guards in `academic-sync.ts` workflow aliases and snapshots.
- Enforce strict string ID comparisons in `storage.ts` deletion tombstones.
- Full esbuild compilation pipeline covering all 10 standalone TypeScript modules.
