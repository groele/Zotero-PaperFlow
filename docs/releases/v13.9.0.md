# Zotero PaperFlow 13.9.0

Release Date: 2026-11-04
Compatibility: Zotero 10.0 - 12.* (Gecko 153+ Web Components)

## Highlights

- **Group Library Full-Lifecycle Support**: Resolved `getByLibraryAndKey` to dynamically support group libraries across PDF opening, item selection, annotation retrieval, and note synchronization.
- **Full-Duplex Prefs Observer Synchronization**: Integrated Zotero preferences with workspace settings via real-time observers and bidirectional messaging.
- **Listener Lifecycle Governance**: Fixed cumulative `document.click` listener retention in manuscript modals and bound preference observers to unload events.
- **Code Deduplication**: Eliminated duplicate status normalization and label helpers between `academic-sync.js` and `kanban-view.js`.
- **Feed Hash Upgrade**: Upgraded `update.json` update hash to `sha512:` specification.
