# Zotero PaperFlow 12.5.2

Released: 2026-10-22

- Prevent data loss during backup imports and restores by serializing host database operations, backing up the latest committed data, validating imported records, and preserving local fields that are absent from an import.
- Return detached snapshots from host reads and saves so unsaved UI edits cannot silently mutate the committed cache.
- Keep native import and restore errors visible instead of silently switching to browser storage.
- Preserve the existing add-on identity, preferences, and database names.

Install `zotero-paperflow-12.5.2.xpi` through Zotero's add-on manager. Do not install the GitHub source archive.
