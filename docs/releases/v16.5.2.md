# Zotero PaperFlow 16.5.2

Release date: 2026-11-12

## Fixes

- **Toolbar button icon restoration**: Removed the top-level Fluent message value from `researchflow-toolbar-tooltip` in `locale/zh-CN/researchflow.ftl` and `locale/en-US/researchflow.ftl`, keeping attribute-only `.tooltiptext` and `.aria-label` so Fluent localization no longer overwrites the XUL `<toolbarbutton>` icon content.
- **Event rail timeline animations restored**: Scoped the blanket `animation: none !important` override in `chrome/content/styles/performance.css` to `@media (prefers-reduced-motion: reduce)` so active timeline track flow (`rfTimelineFlow`) and "Today" pulse ring (`rfTimelineBreath`) animations play normally while still removing heavy `backdrop-filter` and hover transforms.
