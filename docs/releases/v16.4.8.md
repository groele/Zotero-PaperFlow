# Zotero PaperFlow 16.4.8

稿件卡片标题与期刊胶囊学术极简美学重构版。全面重塑手稿卡片顶部序号徽标（`.submission-index`）与期刊名胶囊（`.journal`）的视觉设计，彻底告别过往高饱和电光紫大块与三文鱼粉色呼吸点的撞色刺眼感，建立高质感、高克制、兼顾明暗主题的学术刊物装帧美学。

## 改进与视觉重构重点 (Fixed & Redesigned)

- **中性雅致 Slate 序号徽标 (`.submission-index`)**：
  - 规格从原先臃肿突兀的 38px × 38px 大块优化为小巧克制的 28px × 28px Squircle 方圆徽标（`border-radius: 7px`）；
  - 浅色模式采用极简中性低饱和背景 `#f1f5f9` 与细边框 `#cbd5e1`，配合深灰色数字 `#334155`（`font-size: 13px; font-weight: 700`）与微投影，视觉沉稳内敛；
  - 暗黑模式自动适配半透明 slate 质感 `rgba(148, 163, 184, 0.12)` 与边框 `rgba(148, 163, 184, 0.28)`，数字使用纯净明亮 `#e2e8f0`，兼顾辨识度与护眼。
- **纯白卡片期刊胶囊与宝石蓝指示点 (`.project-info .journal`)**：
  - 高度从 38px 统一缩减为 28px，与序号徽标形成平齐严谨的水平黄金视觉线；
  - 胶囊背景重构为纯白卡片 `#ffffff`（边框 `#cbd5e1`、微投影 `0 1px 2px rgba(0,0,0,0.03)`），与卡片底部操作按钮（「详情」「+ 事件」「管理事件」「分享历程」）高度统一；
  - 核心呼吸点（`::before`）彻底摒弃此前突兀刺眼的三文鱼粉点（`#ef8078`），升级为 6px 宝石蓝活跃呼吸指示点（`#2563eb`，外环 `rgba(37, 99, 235, 0.15)`），在暗黑模式下呈现温和的天空蓝（`#60a5fa`），与整个学术界面节奏浑然一体。
- **全链路测试与架构守卫 (Architecture & Test Integrity)**：
  - 所有 117 个 TypeScript 源码、46 个 CSS 样式表及测试套件恪守 360 行单文件红线（`debtCleared: true`）。
  - 全部 16 项架构守卫、153 项单元测试与打包自检 100% 绿色通过。
