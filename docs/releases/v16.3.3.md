# Zotero PaperFlow 16.3.3

Zotero PaperFlow 正式发布 **16.3.3** 版本。本次维护升级对齐 v15.1.0 经典视觉基线，彻底修复了卡片操作栏功能键消失与点击未响应问题，完整复原「详情」、「+ 事件」、「管理事件」与「🔗 分享历程」四大核心操作按钮，消除了模块间作用域未定义导致的运行时 ReferenceError 异常，全工作区源码、样式与脚本 100% 保持 $\le 360$ 行红线约束与零技术债务。

## 核心修复与体验提升

1. **精准复原经典四功能键卡片操作栏（1:1 对齐 v15.1 视觉标准）**：
   - 彻底解决条目底部操作栏消失问题，移除了顶部标题行冗余按钮，在每篇稿件卡片第一列底端（`.pipeline-actions`）规范复原四大经典操作按钮：
     - `[ 详情 ]`（`.btn-pipeline-open`）：一键跳转至稿件详细编辑与审稿矩阵中心；
     - `[ + 事件 ]`（`.btn-pipeline-add`）：极速展开行内阶段编辑器（Inline Stage Editor），即刻录入投稿、返修、接收等关键里程碑；
     - `[ 管理事件 ]`（`.btn-pipeline-manage`）：弹出完整时间线事件管理器，支持逐节点编辑、重排与删除；
     - `[ 🔗 分享历程 ]`（`.btn-pipeline-share`）：唤起 Share Studio 历程分享工坊，即刻预览并应用 13 款预设学术主题模板；
   - 视觉上对齐 `btn-secondary btn-sm`（高 28px、圆角 6px、雅致中性灰描边与悬浮高亮），告别刺眼杂色，重回极简耐看的高清学术质感。

2. **根除跨模块 IIFE 作用域未声明引起的运行时 ReferenceError 崩溃**：
   - **`isPipelineExpanded` 作用域守卫**：在 `transfer-and-status.ts` 中将仅有类型声明的 `declare var` 转为模块级具名导出变量 `export let isPipelineExpanded = false;`，彻底根除点击「+ 事件」触发 `ReferenceError: isPipelineExpanded is not defined` 导致页面冻结的问题；
   - **`submissionAutoSaveCleanup` 与 `selectedSubmissionId` 状态解耦**：新建专属共享状态子模块 `submission-state.ts`，安全封装自动保存清理器与当前选中条目 ID，杜绝点击「详情」时抛出 `ReferenceError: submissionAutoSaveCleanup is not defined` 导致详情面板无法打开的故障；
   - **`openModal` / `closeModal` 防御性全局查找**：对弹窗控制器调用链增加全局兜底，确保无论脚本加载顺序如何均能 100% 安全唤起与关闭模态窗口。

3. **全架构 360 行硬性红线物理守卫（0 债务治理）**：
   - 新增 `submission-state.ts`（48 行）完全合规；全仓 113 个 TS 模块、45 个 CSS 样式表、20 个测试套件及 5 个构建脚本 100% 遵守 $\le 360$ 行红线；
   - 16 项自动化架构守卫、139 项单元测试以及 5 项打包测试全绿通过。

4. **全链路版本一致性（Zero-Drift 铁律）**：
   - 统一 `manifest.json`、`package.json`、`package-lock.json`、`update.json`、`docs/brand/product.json`、`preferences.xhtml`、`index.html`、`options.html` 以及中英文 README 至权威版本 `16.3.3`。
