# Zotero PaperFlow 15.0.0

Release Date: 2026-11-05
Compatibility: Zotero 10.0 - 12.* (Gecko 153+ Web Components)

## Major Milestone: Migration to Modern esbuild & TypeScript Compilation Pipeline (v15.0.0)

- **现代 esbuild + TypeScript 编译流水线 (Modern esbuild + TypeScript Pipeline)**:
  - 建立 `src/` 现代 TypeScript (TS/ESM) 唯一权威源码树，彻底告别散落手写 JS 结构；
  - 架构清晰分层：`src/index.ts` 聚合根入口、`src/config.ts` 强类型常量、`src/types.ts` 领域模型与契约、`src/addon.ts` 聚合运行时容器、`src/hooks.ts` 规范化生命周期钩子、`src/modules/` 单一职责子模块；
  - 配备严格模式 `tsconfig.json`（ES2022 / ESNext bundler 模式）与沙箱环境全局类型守卫 `typings/global.d.ts`，构建前强制执行 `tsc --noEmit` 静态类型守卫。
- **废弃传统覆盖式 `chrome.manifest` (No Legacy chrome.manifest Overlay)**:
  - 彻底移除仓库根目录与 XPI 安装包内的遗留 `chrome.manifest` 覆盖清单；
  - 全生命周期依托 `bootstrap.js` 原生 `amIAddonManagerStartup.registerChrome` 实现 `content` 与 `locale` 的安全动态注册；
  - 同步更新打包与测试验证脚本，杜绝旧式覆盖结构的维护负担。
- **现代化 `bootstrap.js` 生命周期架构 (Modernized Host Bootstrap)**:
  - 废弃多文件 `Services.scriptloader.loadSubScript` 加载链，统一加载由 esbuild 面向 `firefox140`（Gecko 153+ 现代运行时）编译生成的单一主包 `chrome/content/scripts/index.js`；
  - 完整补齐 `onMainWindowLoad` 与 `onMainWindowUnload` 多窗口动态挂载监听；
  - 在插件卸载与禁用时执行 `ChromeUtils.unload` 脚本注销与缓存清理。
- **工作区全系标准命令对齐 (Unified Workspace Build Commands)**:
  - 统一全系标准命令：`npm run build`（类型检查 -> esbuild 打包 -> 可复现 XPI 构建与更新源同步）、`npm run build:bundle`、`npm run typecheck`、`npm test`；
  - 自动化单测套件 134/134 100% 通过，8/8 项可复现打包策略测试 100% 通过。
