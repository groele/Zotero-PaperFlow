# Zotero PaperFlow 13.8.0

发布日期：2026-11-04。本版本为全量功能细粒度开关治理、设置面板三级层级重构与代码标识对齐发布版（Full Granular Feature Switch Governance, 3-Level Settings Hierarchy Redesign & Identifier Alignment Release），彻底补齐用户自主控制权、消除隐式自动化与集合树污染、规范设置面板视觉层级网格、统一内部日志标识；面向 Zotero 10+ 现代宿主基准（10.0–12.*）。

## 核心改进与特性

1. **补齐四项细粒度功能开关与全链路业务联动 (`prefs.js`, `preferences.js`, `index.js`, `kanban-view.js`, `submissions-view.js`, `options.js`)**：
   - **子笔记自动同步控制 (`autoSyncChildNotes`，默认 `true`)**：
     - 在偏好中提供独立开关，用户可自由选择在手稿保存或关联文献时是否自动同步/覆盖 Zotero 子笔记。关闭后，系统将仅在用户显式点击“📝 同步笔记”时才执行写入，彻底避免非预期的子笔记频繁修改；
   - **管线分类集合自动归入控制 (`autoAddToPipelineCollection`，默认 `true`)**：
     - **杜绝分类树污染**：用户可关闭自动创建和归入「🚀 Zotero PaperFlow 论文管线」分类集合，满足深度定制个人文献库分类结构的用户需求；
   - **论文录用彩带动画控制 (`enableAcceptanceCelebration`，默认 `true`)**：
     - 在写作看板与投稿详情中，当稿件被正式录用（accepted）时，允许用户根据办公或严肃研讨环境自主开启或关闭全屏彩带动效与喜报弹窗；
   - **本地自动备份开关 UI 补齐 (`autoBackupOnSave`，默认 `true`)**：
     - 在模块 4 数据存储区补齐复选框，让用户可直观查看和控制本地保存时是否自动轮转维护历史版本安全快照。

2. **设置面板架构重构与三级层级规范对齐 (`preferences.xhtml`, `preferences.css`, `preferences.js`)**：
   - 严格遵循 `AGENTS.md` §4.1 与 §4.2 卡片容器基准网格与数学对齐规范：
     - 卡片统一水平内边距 `padding-inline: 16px`；
     - 一级标题与概述说明从 `16px` 起始；
     - 二级主控制项图标从 `16px` 起始，文字标签严格锚定在 `40px`（`16px + 24px`）黄金对齐基准线；
     - 三级从属说明与控件通过 `margin-inline-start: 24px` 严格对齐至 `40px` 垂直线上；
     - 模块 5（版本信息与运行诊断）彻底重构为与其他模块一致的标准卡片化容器，消除过往普通 div 造成的视觉节奏断层；
     - 单层折叠、默认展开首组，消除多层嵌套。

3. **代码标识与日志对齐 (`index.js`)**：
   - 统一清理宿主内部与报错日志中的历史 `[ResearchFlow]` 前缀，全面规范为统一标识 `[PaperFlow]`；
   - 保持历史笔记检测双向兼容：同时识别 `[ResearchFlow]`、`ResearchFlow for Zotero`、`[PaperFlow]` 与 `Zotero PaperFlow`，老笔记与新笔记无缝融合。
