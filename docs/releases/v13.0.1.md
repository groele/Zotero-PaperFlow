# Zotero PaperFlow 13.0.1

发布日期：2026-11-02。本版本为架构深度模块化重构与工程优化版本（Maintenance & Refactoring Release），彻底解决长久以来业务逻辑堆砌在单体脚本中的可维护性痛点，分门别类建立 8 大独立业务模块与 10 大宿主模块体系。

## 核心优化与架构重构

1. **工作台单体代码解耦与 8 大独立业务子模块建立**：
   - 原有长达 **8,146 行** 的单体大文件 `options.js` 精细梳理重构，主入口精简 **94.2%**（压缩至 474 行），专注承担路由调度、全局弹窗、接受庆祝动画与 Zotero 宿主桥接；
   - 按照业务职责彻底拆解为 8 个高内聚、低耦合的标准模块并归档在 `chrome/content/scripts/modules/`：
     - **`i18n.js`**（1,429 行）：多语言翻译字典（中/英）、动态语言切换、主题模式检测与 DOM 国际化文本绑定；
     - **`timeline-engine.js`**（1,000 行）：时间线节点模型、日期差值运算、周期耗时分析、阶段状态归一化与接受状态推断；
     - **`academic-sync.js`**（579 行）：手稿与投稿状态双向联动同步、学术标题清洗、DOI 智能提取规范化、作者列表解析与学术条目匹配；
     - **`share-studio.js`**（424 行）：论文投稿历程分享图生成引擎、Canvas 高清渲染、事件流聚合与 PNG 导出；
     - **`dashboard-view.js`**（723 行）：科研总览仪表盘视图、实时统计交互式过滤卡片、时间线甘特流程图与阶段编辑抽屉；
     - **`kanban-view.js`**（1,069 行）：手稿看板视图、多阶段卡片拖拽流转、新增/编辑手稿模态表单与快速导入；
     - **`submissions-view.js`**（1,816 行）：投稿与同行评审追踪视图、审稿人回复矩阵（Rebuttal Matrix）编辑器、审稿检查清单、自动保存保护机制与期刊门户管理；
     - **`settings-view.js`**（721 行）：多云私有同步（WebDAV / GitHub PAT）配置面板、连接自检、数据库 JSON 导入/导出与灾备恢复。

2. **宿主运行时 `index.js` 10 大架构模块边界明确化**：
   - 对宿主运行核心 `index.js`（2,899 行）进行深度检验，梳理并建立 10 大核心架构模块的物理边界与导航：
     - **模块 1**：文献序列化与 APA / BibTeX 引用生成引擎；
     - **模块 2**：宿主运行时首选项、本地化与观察者；
     - **模块 3**：原生文献库与阅读器上下文菜单；
     - **模块 4**：宿主数据库存储、快照持久化与并发事务原子队列；
     - **模块 5**：原生平台文件选择器与数据导出（`nsIFilePicker`）；
     - **模块 6**：Zotero 云端子笔记自动同步引擎；
     - **模块 7**：窗口生命周期管理、拆分独立阅读器穿透与 DOM 工具栏按钮；
     - **模块 8**：全局导航、窗口打开器与 PDF 伴读联动；
     - **模块 9**：Web Components 条目信息面板注入卡片；
     - **模块 10**：扩展注销卸载与资源彻底清理。

3. **代码健康度与权威版本同步收敛**：
   - 彻底修复 `index.js` 内部旧版本号残留回退；
   - 统一 `manifest.json`、`product.json`、`preferences.xhtml`、`index.html`、`options.html`、`options.js`、`update.json` 全平台版本标识至 `13.0.1`。

4. **全量自动化测试套件与可复现打包验证**：
   - 38 项 Node.js 单元测试全部通过（覆盖条目只读防护、垃圾桶防护、管线集合防护、时间线状态推断、图片导出防重、存储并发控制等）；

   - 生成全新可复现二进制包 `zotero-paperflow-13.0.1.xpi` 并完成 LF 换行与哈希校验。
