# Zotero PaperFlow 12.5.4

Released: 2026-10-24

- Report local-storage quota or permission failures as failed saves. Preserve the committed cache and prevent a false success state when browser persistence is unavailable.
- Include revision-safe saves, independent-edit merging and conflict-draft recovery from the unreleased 12.5.3 source.
- Correct the automatic update hashes for both the current and legacy add-on identities.
- Add reproducible XPI builds and mandatory checks of runtime bytes, archive entries, versions, identities, compatibility, immutable asset URLs and hashes.
- Provide explicit hash synchronization and verification-only commands with isolated release-package regression tests.

## Verification

The 56 JavaScript regressions and seven release-package regressions pass. In an isolated Windows Zotero 10.0.6 profile, nine real database checks and a fresh-process restart check passed, including independent-edit merging and conflict-draft recovery. External sync providers and the full declared Zotero compatibility range are not covered by these tests. The add-on ID, preferences and database names are unchanged.

Install the Release XPI through Zotero's add-on manager. The existing 12.5.3 tag remains immutable; 12.5.4 supersedes its incomplete release preparation.
