# Zotero PaperFlow 12.6.1

发布日期：2026-11-02。本版本为向后兼容的维护与优化版本（Patch Release），全面对齐 Zotero 10+ 宿主基准规范与安全防护。无需数据库迁移。

## 核心优化与改进

1. **Zotero 10+ 现代架构基准对齐**：
   - 清单与自动更新源统一面向 **Zotero 10+**，声明 `strict_min_version: "10.0"`，`strict_max_version: "12.*"`；
   - 移除过时的 Zotero 7/6.999 假设，偏好设置页与产品文档同步声明为 Zotero 10+ (Gecko 153+)。
2. **条目状态与只读防护（Read-only Guard）**：
   - 数据写入链路（`syncManuscriptToChildNote` 与 `syncStatusTagToItem`）深度集成 `target.isEditable()` 原生安全检查；
   - 用户在浏览只读群组库（Group Library）或回收站（Trash，`target.deleted`）中的文献时，阻止非法写入，条目信息面板中的「📝 同步笔记」及管线创建/关联按钮自动降级为禁用只读状态（`disabled = true`），彻底杜绝非法修改与同步冲突。
3. **多窗口与独立阅读器标签页遍历穿透**：
   - 宿主初始化与广播通信适配 Zotero 10 独立拆分阅读器窗口（Detached Window），借助 Gecko 原生 `Services.wm.getEnumerator("")` 全局窗口枚举器穿透扫描所有活动窗口，确保外置阅读器与多窗口界面即时生效。
4. **品牌规范与版本一致性收敛**：
   - 全面核对清理用户可见文本中的残留旧名称，阅读器菜单项更正为 `📝 摘录至 Zotero PaperFlow 稿件研究笔记`，子笔记生成签名对齐；
   - 修复偏好设置导出诊断报告中的硬编码旧版本号，动态绑定权威版本；
   - 统一 `manifest.json`、`preferences.xhtml`、`index.html`、`options.html`、`options.js`、`update.json` 的版本标识为 `12.6.1`。
5. **条目面板侧栏按需启用与宿主生命周期清理（Lifecycle Cleanup）**：
   - 引入 `enableItemPane` 首选项并在原生设置面板提供开关卡片（默认关闭以保持主界面整洁），支持在条目右侧信息面板按需启用稿件管线卡片；
   - 首选项 Observer 实时监听侧栏设置变更并动态注册/注销；
   - 优化插件卸载/停用流程，在 `shutdown()` 中显式注销 `_prefPaneID` 与 `itemPaneSectionID`，防止插件重新启用时产生重入与内存泄漏。
6. **工程规范与测试套件完善**：
   - 建立仓库专属 `AGENTS.md` 规范；
   - 新增针对条目只读防护、版本统一性、侧栏按需注册与生命周期清理的自动化单元测试（总单测用例增至 97 项，100% 通过）；
   - 通过可复现打包工具生成产物并更新 `update.json` 校验哈希。
