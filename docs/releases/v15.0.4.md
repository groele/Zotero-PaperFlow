# Zotero PaperFlow 15.0.4

Release Date: 2026-11-05
Compatibility: Zotero 10.0 - 12.* (Gecko 153+ Web Components)

## Inline Review Event Editor Density and Layout

- Compress the editor into a purposeful two-row workspace instead of stacking two large sections vertically.
- Keep all key event, date, deadline, and review-decision controls in the primary row.
- Use the full card width, reserve the second row for notes and actions, and keep the save action anchored on the right.
- Preserve accessible labels, review-only visibility, keyboard focus, and narrow-window fallback behavior.

Verification: `npm test` and `npm run build` passed. The packaged XPI, SHA-256 checksum, and update feed are generated during release verification.
