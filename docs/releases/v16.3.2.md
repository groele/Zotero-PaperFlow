# Zotero PaperFlow 16.3.2

Zotero PaperFlow 正式发布 **16.3.2** 版本。本次维护升级彻底修复了 CSS 媒体查询花括号解析异常导致的仪表盘条目卡片操作按钮样式失效问题，完整恢复并高亮呈现每篇论文的「+ 事件」（添加时间节点）与「📤 分享历程」（分享事件流程卡片）快捷操作，同时全面落实全工作区代码与样式单文件 360 行红线规范治理，达成全链路零技术债务。

## 核心修复与体验提升

1. **彻底恢复「+ 事件」与「📤 分享历程」双重动作按钮**：
   - **双轨完备入口**：
     - **顶部标题行**（`.project-heading-row`）：在标的序号与期刊徽标右侧提供极速快捷入口——高对比度墨绿渐变的 `+ 事件`（`.btn-quick-add-event`）与高辨识度天青渐变的 `📤 分享历程`（`.btn-quick-share`）；
     - **底栏动作工具栏**（`.pipeline-actions`）：在卡片底部统一呈现 `详情`（`.btn-pipeline-open`）、`+ 事件`（`.btn-pipeline-add`）、`管理事件`（`.btn-pipeline-manage`）与 `📤 分享历程`（`.btn-pipeline-share`）全功能四键矩阵；
   - **13 款预设分享模板瞬间唤起**：点击分享历程即刻打开 Share Studio 弹窗，支持 Estuary、Iris、Amber、Journal、Conference、Archive、Paper、Ink、Blueprint、Minimal、Cyber、Aurora、Terminal 等 13 种学术分享主题，一键导出高清 PNG 或 SVG。

2. **根治 Gecko/Zotero CSS 语法与花括号解析中断**：
   - 彻底排查并修复 `event-rail.css` 子模块拆分过程中因 `@media (max-width: 1220px)` 与 `@keyframes` 未完全闭合导致的样式级联失效问题；
   - 保证工作区全量 45 个 CSS 样式表 100% 花括号对称平衡，所有 `.pipeline-actions` 与快捷按钮无论在暗色还是亮色模式下均获得显式 flex 布局与高优先级渲染。

3. **全架构 360 行硬性红线物理守卫（0 债务治理）**：
   - 全面重构并解耦核心构建与打包脚本：
     - 拆分 `scripts/package-xpi.mjs` 为 `package-xpi.mjs`（357 行）与底层纯 Node.js ZIP 处理库 `package-xpi-zip.mjs`（149 行）；
     - 拆分超限测试套件为细粒度子测试文件（`dashboard-render-interactions.test.js`、`database-safety-merge.test.js`、`export-cover-progress.test.js` 等）；
     - 样式表全量解耦分层（`event-rail-card.css`、`event-rail-columns.css`、`event-rail-animations.css` 等）；
   - 自动化架构守卫（`architecture-guard.mjs`）穿透扫描 112 个 TS 源码模块（$\le 340$ 行）、45 个 CSS 样式表（$\le 360$ 行）、20 个单元测试套件（$\le 360$ 行）与 5 个构建脚本（$\le 360$ 行），全量合规，技术债务清零。

4. **全链路版本一致性与防漂移**：
   - 全面统一 `manifest.json`、`package.json`、`package-lock.json`、`update.json`、`docs/brand/product.json`、`preferences.xhtml`、`index.html`、`options.html` 以及中英文 README 至权威版本 `16.3.2`。
