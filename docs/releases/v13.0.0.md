# Zotero PaperFlow 13.0.0

发布日期：2026-11-02。本版本为重大里程碑升级（Major Milestone Release），全面实现商业产品级别的细致打磨、三级设置层级几何对齐、深度群组库与只读防护体系以及多窗口动态穿透。

## 核心优化与特性

1. **设置界面三级层级与边缘距离标准规范（2026-11-02 统一基准）**：
   - 严格落实设置面板卡片化容器内三级层级体系与数学对齐规范：
     - **容器基准**：卡片统一采用 `padding-inline: 16px` 标准水平内边距；
     - **一级大标题与概述说明**：标题区通栏平铺（`margin: -16px; padding: 12px 16px;`），与概述文字左边缘严格对齐于 `16px` 起始线；
     - **二级主控制项与 40px 黄金基准线**：主复选框图标左边缘紧贴 `16px`，文字标签严格对齐于 `40px` 黄金基准线；
     - **三级从属说明与控件**：从属说明、从属单选组及从属复选框统一声明 `margin-inline-start: 24px`，文字与图标精准垂直对齐于 `40px` 竖线，消除任何视觉漂移；
     - **嵌套服务配置卡片**：数据存储与外部同步子卡片统一声明 `padding: 12px 16px;` 标准网格，严禁不规则内边距。

2. **商业级条目状态与只读防护（Read-only Guard）**：
   - 全面覆盖核心操作链路：`syncManuscriptToChildNote`、`syncStatusTagToItem` 以及 `addItemToPipelineCollection`；
   - 深度集成 `target.isEditable()` 与 `target.deleted` 原生安全检查；
   - 用户在浏览只读群组库（Group Library）或回收站（Trash）条目时，插件自动阻断非法写操作与脏同步，条目面板与控制台按钮安全降级，防止网络同步冲突与数据损坏。

3. **群组库（Group Library）与多库环境深度适配**：
   - 跨窗口桥接处理器（`RESEARCHFLOW_SELECT_ITEM`、`RESEARCHFLOW_OPEN_PDF`、`RESEARCHFLOW_SYNC_NOTE`、`RESEARCHFLOW_GET_ANNOTATIONS`、`RESEARCHFLOW_SYNC_STATUS_TAG`、`RESEARCHFLOW_ADD_TO_PIPELINE_COLLECTION`）彻底解绑硬编码的 `userLibraryID`；
   - 动态解析条目所属真实 `libraryID`（`data.libraryID || target.libraryID || Zotero.Libraries?.userLibraryID || 1`），原生支持群组库与多个人库无缝操作；
   - 管线集合命名标准化为 `🚀 Zotero PaperFlow 论文管线`，并向前兼容现存 `ResearchFlow` 管线。

4. **多窗口与独立阅读器标签页遍历穿透（Detached Reader Tabs/Windows）**：
   - 全面基于现代化 Gecko（Gecko 153+ ESM、Web Components 与现代事件机制）；
   - 凡涉及阅读器摘录、侧边栏通知与浮层渲染的 DOM 操作，借助 Gecko 原生 `Services.wm.getEnumerator("")` 全局窗口枚举器穿透扫描所有活动窗口中的文档，确保外置阅读器与独立拆分标签页中的交互即时响应。

5. **全系品牌与体验精细打磨**：
   - 原生 Toast 浮窗提示统一为 `Zotero PaperFlow · ${title}` 优雅标题规范；
   - 状态标签双向兼容 `PaperFlow/` 与旧版 `ResearchFlow/` 标签体系；
   - 全面核对清单、设置页、面板徽标及更新配置，权威版本号全系统一收敛至 `13.0.0`。

6. **全量自动化测试套件与品质管控**：
   - 包含只读防护、群组库管线集合防护、版本一致性校验、侧栏生命周期、双向数据同步、时间线状态归一等单元测试，100% 通过；
   - 符合项目长期规范与可复现打包要求。
