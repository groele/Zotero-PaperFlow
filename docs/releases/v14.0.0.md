# Zotero PaperFlow 14.0.0

Release Date: 2026-11-04
Compatibility: Zotero 10.0 - 12.* (Gecko 153+ Web Components)

## Major Architecture & Localization Milestone

- **Zero Hardcoded UI Text (Fluent 本地化规范化)**: `preferences.xhtml` 设置模板中 38 个中文硬编码节点 100% 改造为 Fluent 驱动（`data-l10n-id`），中英文字典（`researchflow-pref-*`）严格对称，动态脚本挂载支持。
- **投稿审稿视图模块化解耦**: 抽离学术自述信、审稿意见解析与学术答复信排版引擎至独立模块 `academic-exporter.js`，`submissions-view.js` 视图精简 752 行。
- **存储与多云同步协议解耦**: 抽离 WebDAV HTTP DAV 与 GitHub REST API 协议层至独立模块 `cloud-sync.js`，`storage.js` 专注于本地原子数据库管理，代码行数缩减至千行以内（908 行）。
- **宿主核心入口精简重构**: 抽离 Module 1 学术引文与文献序列化模块至独立模块 `academic-citation.js`，`index.js` 聚焦生命周期与原生集成，精简近 600 行。
- **构建测试全量闭环**: 134/134 项单元测试通过，XPI 自动化构建与更新源哈希自动同步。
