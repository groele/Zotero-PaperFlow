# Zotero PaperFlow 16.4.7

时间线提醒修回倒计时激活版。彻底激活看板「🔔 时间线提醒」（Timeline Alerts）模块的返修稿件告警逻辑，直接提取稿件级权威修回截止日期（`revisionDueDate`），智能计算精准倒计时并渲染分级动态徽标（🚨 已逾期 X 天 / 🚨 今天截止 / ⚠️ 仅剩 X 天 / 📅 剩 X 天），支持一键导出单篇与全部修回截止日历（.ics）。

## 改进与修复重点 (Fixed & Improved)

- **看板时间线提醒返修截止倒计时激活 (Activated Revision Due Countdown in Timeline Alerts)**：
  - 修复此前看板「🔔 时间线提醒」在稿件处于返修状态时无法展示修回告警的核心根因：此前逻辑仅遍历节点，而审稿意见节点已标记为完成、修改稿节点尚未设定截止日期，导致稿件级权威修回截止日期（`revisionDueDate`）被旁路跳过。
  - 现直接在活跃稿件级别提取 `revisionDueDate`，调用倒计时计算引擎（`getRevisionCountdownMeta`）动态判定：
    - **已逾期** (`diffDays < 0`)：渲染 `🚨 已逾期 X 天`（危险红徽标 `badge badge-danger`）
    - **今天截止** (`diffDays === 0`)：渲染 `🚨 今天截止`（高危红徽标 `badge badge-danger`）
    - **即将截止** (`diffDays <= 7`)：渲染 `⚠️ 仅剩 X 天`（警告琥珀橙徽标 `badge badge-warning`）
    - **未来截止** (`diffDays > 7`)：渲染 `📅 剩 X 天`（信息蓝徽标 `badge badge-info`）
    - **返修中但未定截止**：渲染 `⚠️ 待设截止日`，提示研究者及时录入返修截止日
  - 智能避免里程碑节点与修回权威截止日期的重复告警，保证提醒列表清爽、无冗余。
- **紧急度排序与一键日历同步 (.ics Calendar Sync)**：
  - 告警列表按剩余天数绝对紧急程度严格排序：已逾期 > 今天截止 > 仅剩少天 > 未来截止，最紧迫的修回事项始终置顶。
  - 每条返修告警右侧提供专属 `📅 .ics` 导出按钮，点击即刻下载该稿件的修回截止日历事件，与 Apple 日历、Google Calendar、Outlook 毫秒级同步；看板顶部同时保留「导出全部修回日历」能力。
  - 点击告警条目卡片，直达对应稿件的时间线节点抽屉面板，极速编辑修改进度。
- **架构与质量守卫 (Architecture & Guard Integrity)**：
  - 全量 117 个 TypeScript 源码模块、46 个 CSS 样式表及所有测试套件严格恪守 360 行单文件红线（`debtCleared: true`）。
  - 全部 16 项架构守卫、153 项单元测试、打包自检与标签自检 100% 绿色通过。
