# Zotero PaperFlow 16.3.1

Zotero PaperFlow 正式发布 **16.3.1** 版本。本次维护升级彻底解决侧栏页面切换卡死、严格模式全局未声明变量引用报错、投稿条目「+ 新建事件」与「📤 分享历程」动作按钮缺失，并进一步强化条目序号徽章与期刊名称的视觉冲击力。

## 核心修复与体验提升

1. **页面切换与侧栏导航彻底解卡**：
   - 彻底修复 `activateWorkspaceView` 中访问未声明全局变量 `submissionAutoSaveCleanup` 和 `acceptanceCelebrationCleanup` 导致的 `ReferenceError` 致命异常；
   - 消除 `transfer-and-status.ts` 中未声明的 `isPipelineExpanded` 与 `currentDashboardFilter` 变量引用报错；
   - 视图激活器增强容错重渲染逻辑，确保从任一工作台或侧栏菜单无缝切换至主仪表盘、看板、稿件列表与多云设置。

2. **投稿条目动作按钮全景复现**：
   - 在主仪表盘 4 列事件轨卡片的首行标题栏（`.project-heading-row`）与底栏动作区（`.pipeline-actions`）全面显式复现 `+ 新建事件`（`.btn-quick-add-event`, `.btn-pipeline-add`）与 `📤 分享历程`（`.btn-quick-share`, `.btn-pipeline-share`）按钮；
   - 稿件卡片列表与条目详情面板同样对称配备 `btn-sub-card-share` 与 `btn-share-sub-journey`；
   - 点击即可瞬间唤起全套 13 款预设分享模板（Estuary / Iris / Amber / Journal / Conference / Archive / Paper / Ink / Blueprint / Minimal / Cyber / Aurora / Terminal），支持一键生成高清学术历程分享卡片。

3. **标的序号与期刊名称视觉冲击力强化**：
   - 标的序号徽章（`.submission-index`）尺寸扩展至 38px × 38px，采用高饱和皇家蓝/深靛蓝渐变背景与 16px 特粗白字，搭配精美拟态立体投影；
   - 期刊名称胶囊（`.project-info .journal`）尺寸加码至 38px 最小高度、15.5px 字号与 800 字重，内嵌醒目 `●` 视觉锚点与双层柔光边界，暗黑模式自适应高对比色彩。

4. **顶部 KPI 统计计数动态自愈**：
   - 为 `renderDashboard()` 中的已接收发表、在审与总投稿计数更新逻辑增加强健的 `checkAccepted` 容错探测器，杜绝因模块加载时序差异导致的计数显示为 0；
   - 全面启用 `animateMetricValue` 数字跳动平滑动画与无障碍属性同步。
