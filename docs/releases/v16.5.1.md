# Zotero PaperFlow 16.5.1

稳定性与数据一致性修复版。重点修复看板状态持久化缺失、模态框多轮次状态串改、UTC/本地日历及审稿周期偏差、未绑定 Zotero 条目误写回与插件停用保存竞态问题，并补全设置面板观察器与 Fluent 文案同步。

## 修复与改进 (Fixed & Improved)

- **看板持久化与状态校验 (`P0`)**：补齐 `persistManuscriptStatusChange`，在克隆副本上进行状态变更校验与 `storage.saveAll` 原子持久化，保存失败时自动回滚；补全 `validateLinkedManuscriptStatus` 对 `planning` 与 `in_progress` 的白名单支持。
- **多轮次状态与当前投稿裁决 (`P1`)**：修复 `setManuscriptStatus` 批量篡改所有非拒稿轮次的缺陷，改为仅同步当前最新轮次；优化 `getCurrentSubmission` 排序优先级，确保未被取代且仍在审中的新轮次优先于历史 `accepted`/`published` 轮次；新建或流转轮次统一写入规范 `round` 与 `previousSubmissionId`。
- **本地日历与审稿周期统计 (`P1`)**：统一 `todayString`、`addDays(+14)`、`computeNodeStatus` 与 `getRevisionCountdownMeta` 为本地日历计算，修复跨时区日期偏移 1 天的问题；修复 `getSubmissionCycleTime` 在无投稿日期或负耗时场景下误算耗时，并移除无日期修回提醒中写死的 `days: 1`。
- **Zotero 条目绑定保护与停用竞态 (`P1`)**：强化 `syncManuscriptToChildNote` 的条目键严格匹配，禁止对已解绑（`zoteroUnbound` / `zoteroItemKey: null`）条目通过 DOI 误写回子笔记，统一使用 `round ?? roundIndex`；插件 `shutdown()` 显式标记 `_disposed = true` 并排空 `_saveQueue` / `_uiStateQueue`，防止停用后继续写盘。
- **时间线、设置观察器与工具栏本地化 (`P2`)**：修复 `setTimelineNodeDate` 设置 `completeDate` 时覆盖既有 `planDate`/`dueDate` 的问题；修复 `shouldRunCloudSync` 忽略 `autoSync` 偏好的问题；补齐设置面板 `Zotero.Prefs` 实时监听、容器 ID 映射与 Fluent 动态翻译，以及工具栏按钮 `data-l10n-attrs="tooltiptext"`。
