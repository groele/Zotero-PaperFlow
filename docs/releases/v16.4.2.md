# Zotero PaperFlow 16.4.2

Restore the Share Studio 9 editorial poster workbench, upgrade the Timeline Events Manager modal, and harden Zotero upgrade cache invalidation and preference persistence.

## Fixed & Improved

- **Editorial Share Poster & Share Studio 9 Workbench**:
  - Restored the `layout-builder.ts` + `constants-and-data.ts` + `canvas-renderer.ts` editorial poster engine (`496 - x` orbital brand seal clearance in the masthead, stacked `event-date` + `event-year` typography, right-aligned `timeline-count` & `footer-note`, square nodes on blueprint/conference/archive themes, and zero timeline rail overshoot), keeping backward compatibility with legacy helpers (`getShareCardLayout`, `renderSubmissionShareCard`, `wrapTextLines`).
  - Restored the Share Studio 9 modal (`304px` control rail, `#share-appearance` selector, collapsible `<details open>` 3-column `Aa` 13-theme swatch gallery, 2-column single-checkbox visibility chips without duplicate checkmarks, `brandSize` selector synced with footer visibility, timeline start selector, size & resolution controls, zoomable live preview stage, and fixed footer actions).
  - Resolved CSS conflicts in `share-studio.css` against global `readability.css` / `modals-base.css`: enforced Light/Dark token contrast, prevented dropdown chevron tiling (`background-color: var(--input-bg)` + `background-repeat: no-repeat`), bounded preview height cleanly inside compact/mobile viewports, and hid inactive error/loading overlays via `#modal-body [hidden]`.
- **Data Integrity & Persistence Safety**:
  - Fixed `persistSharePreferences` so `storage.loadAll()` no longer overwrites live in-memory `db.submissions`, and guarded non-object return values from `saveAll`.
- **Timeline Events Manager & Localization**:
  - Redesigned `openTimelineEventManager` and `event-editor.css` into a responsive two-column status card layout (`--event-color` tokens for completed/in-progress/overdue/upcoming milestones, journal pill badge, inline edit triggers, and prominent `+ Add Event` transition to `.inline-stage-editor`).
  - Localized milestone labels and aligned zh/en workflow keys to prevent raw i18n key leaks.
- **Upgrade Cache Refresh**:
  - Added `Services.obs.notifyObservers(null, 'startupcache-invalidate')` during add-on startup/shutdown in `bootstrap.js` so updated scripts and styles take effect reliably after XPI installation.
- **Modular Architecture & Regression Tests**:
  - Extracted `src/modules/share-card/layout-builder.ts` and kept all 117 TS modules, 46 CSS stylesheets, 25 test suites, and 5 scripts strictly within the 360-line ceiling (`debtCleared: true`).
  - Added `tests/share-and-event-modal-ui.test.js` covering editorial poster layout geometry, Share Studio 9 markup/CSS rules, non-destructive `persistSharePreferences`, and Timeline Event Manager localization & interaction.

## Compatibility and Validation

- Compatibility range remains Zotero `10.0` – `12.*`; all internal add-on IDs, preference keys, and database schemas remain unchanged.
- Verified locally with `npm run build` (`tsc --noEmit`, 16/16 `architecture-guard` checks, esbuild bundling, reproducible XPI packaging, and `update.json` SHA-512 verification) and `npm test` (149/149 unit tests, packager self-tests, and SemVer tag checks).
- Verified visually via headless Microsoft Edge (`file://` workspace pages across Light & Dark themes and `1440×900`, `1024×523`, `640×800` viewports on both `index.html` and `pages/options.html`). Running inside a live Zotero desktop session requires user reinstallation of `zotero-paperflow-16.4.2.xpi` and a clean restart.
