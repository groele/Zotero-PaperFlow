# Zotero PaperFlow 16.0.0

Zotero PaperFlow 正式发布 **16.0.0** 大版本，标志着全系统一大版本（Zotero Flow Unified Major Release 16.0.0）协同确立。

## 🌟 核心升级与特性

1. **统一全系大版本号**：跃升至 16.0.0，与 Zotero Flow 家族其余六大插件保持完全一致的版本号与协同发布契约；
2. **彻底规范 Gecko 153 DOM 窗口解析**：消除废弃的 `ownerGlobal` 属性依赖，全面升级为 W3C 标准 `ownerDocument?.defaultView`，保障未来独立阅读器拆分窗口的稳健交互；
3. **特权通信桥梁现代化**：优化 Chrome 协议沙箱探测逻辑，使用特权全局 `Cc` / `Ci` 实现与 Zotero 宿主的高速桥接；
4. **架构守卫与 360 行红线**：45 个 TypeScript 源码模块 100% 恪守 360 行上限约束（0 债务）；
5. **纯 Node.js 工程化交付流水线**：打包、自检、SHA-256/512 计算与验证套件全部由纯 Node.js 驱动，零外部工具链依赖。
