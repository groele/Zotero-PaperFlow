# Zotero PaperFlow 13.0.2

发布日期：2026-11-02。本版本为紧急修复与稳定性增强版本（Hotfix & Stability Release），彻底修复模块化解耦后由于视觉元数据丢失导致的仪表盘主页面管线卡片无法渲染的问题。

## 核心修复与改进

1. **修复仪表盘主页面管线时间线卡片渲染崩溃**：
   - 修复在 `renderDashboard()` 流程中调用 `getTimelineTypeMeta()` 时抛出 `ReferenceError: typeMeta is not defined` 导致整个管线渲染中断的致命错误；
   - 在 `modules/timeline-engine.js` 中完整补齐 `typeMeta` 视觉色彩与国际化映射定义（涵盖 research、writing、submission、review、revision、rejection、publication、special 各阶段色彩）；
   - 彻底清理 `modules/share-studio.js` 末尾残留的损坏代码片段，杜绝脚本语法解析错误。

2. **测试套件扩充与全量端到端验证**：
   - 新增 `tests/dashboard-render.test.js` 端到端回归测试，覆盖所有拆分业务模块在真实环境中的协同加载、`typeMeta` 映射有效性以及 `renderDashboard()` 渲染卡片数量与时间线提醒容器验证；
   - 更新 `tests/import-ui-safety.test.js` 对齐解耦后的 `modules/settings-view.js` 模块源码路径；
   - 100 项 Node.js 单元测试（包括只读防护、并发存储、冲突恢复、时间轴告警与渲染校验）100% 满分通过。

3. **版本号统一收敛**：
   - 统一 `manifest.json`、`product.json`、`preferences.xhtml`、`index.html`、`options.html`、`options.js`、`index.js`、`update.json` 全平台版本标识至 `13.0.2`。
