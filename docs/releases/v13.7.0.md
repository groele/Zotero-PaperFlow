# Zotero PaperFlow 13.7.0

发布日期：2026-11-04。本版本为群组库多库支持、全链路设置双向桥接与全局监听器生命周期防泄漏治理发布版（Multi-Library Group Support, Prefs Full-Duplex Bridging & Listener Lifecycle Defense Release），彻底解决群组库条目关联失效缺陷、消除 Zotero 原生首选项与工作台配置断层、消除模态窗口与首选项面板的累积事件泄漏，保持 Zotero 10+ 现代宿主基准（10.0–12.*）。

## 核心改进与特性

1. **群组库（Group Library）多库条目解析与全功能支持 (`index.js`, `zotero-bridge.js`, `kanban-view.js`, `submissions-view.js`, `dashboard-view.js`)**：
   - 彻底破除过去在 `zotero-bridge.js` 与 `index.js` 中硬编码 `userLibraryID || 1` 的历史缺陷；
   - 引入全新的多库智能条目检索与解析引擎：
     - `Zotero.ResearchFlow.findItemByKey(itemKey, libraryID = null)` 与前端 `resolveZoteroItem(zotero, itemKey, libraryID = null)`；
     - 优先按条目显式 `libraryID` 定位；若未指定则依次检索用户个人库（`userLibraryID`）与所有可访问的群组库（`Zotero.Libraries.getAll()`）；
   - 在数据模型中全面升级，手稿（Manuscript）条目持久化存储 `zoteroLibraryID`；
   - 包含打开 PDF、定位条目、提取 PDF 划线批注、同步子笔记、同步阶段标签、加入论文管线分类集合在内的所有桥接方法，全面支持传入 `libraryID`，群组库文献关联、同步与联动完全顺畅。

2. **Zotero 原生设置页（Zotero.Prefs）与工作台（db.settings）全双工双向桥接 (`index.js`, `storage.js`, `preferences.js`, `zotero-bridge.js`)**：
   - 彻底修复 `preferences.js` 写入的 `Zotero.Prefs` 与工作台脚本（`storage.js`, `submissions-view.js`, `kanban-view.js`）仅读取 `db.settings` 脱节的断层缺陷；
   - 宿主端新增 `getSyncedSettingsFromPrefs(existingSettings = {})` 方法，系统读取与保存 `researchflow-data.json` 时自动将 18 项核心偏好同步对齐到 `db.settings`；
   - 前端 `StorageEngine.ensureDbShape()` 加载时自动同步宿主偏好；`ZoteroBridge.getPref(key, defaultValue)` 优先直读宿主实时偏好；
   - 在原生设置页修改偏好时，`notifyConfigChanged()` 不仅实时更新内存缓存，更向所有打开的伴读窗、主标签页广播 `RESEARCHFLOW_PREF_CHANGED` 消息；
   - 前端全链路即时响应：
     - `showJournalPortals`：实时显示或隐藏期刊系统官网直达入口；
     - `collapseEmptyKanbanStages`：在看板与仪表盘中实时折叠空白阶段列；
     - `locateOnManuscriptClick`：在看板点击稿件卡片主体时联动 Zotero 选中对应条目；
     - `autoLinkSelectedPaper`：新建稿件弹窗时智能联动选中条目；
     - `defaultRebuttalExportFormat`：审稿回复信与修回矩阵导出弹窗默认格式智能切换（LaTeX / Markdown / Word / Table / Cover Letter）。

3. **模态窗生命周期管理与全局监听器泄漏彻底治理 (`options.js`, `kanban-view.js`, `preferences.js`)**：
   - 在 `options.js` 中构建统一的模态窗生命周期清理体系 `registerModalCleanup(fn)`，在任何模态窗关闭（`closeModal()`）或重新打开时确保安全触发清理并释放资源；
   - 修复 `kanban-view.js` 的 `openManuscriptModal()` 每次打开都会给 `document` 添加下拉列表点击关闭监听器导致的严重累积泄漏问题；
   - 修复 `preferences.js` 的 `MutationObserver` 未绑定窗口 `unload` 断开的潜在泄漏，在宿主窗口关闭时防御性注销观察者。
