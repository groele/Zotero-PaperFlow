# Zotero PaperFlow 13.0.4

发布日期：2026-11-02。本版本为稿件条目删除修复与架构解耦增强版本（Manuscript Deletion & Architectural Decoupling Release），在手稿看板卡片和编辑模态框中提供安全的删除入口，级联清理关联投稿记录并同步写入删除墓碑（Tombstones），同时对核心模块架构进行解耦优化，显著提升代码可维护性。

## 核心修复与改进

1. **补全手稿条目安全删除入口与全流程级联机制**：
   - 彻底修复手稿卡片只有“编辑”按钮、编辑模态框底部只有“保存修改”而无法删除条目的核心缺陷；
   - 在看板卡片（Kanban Card）控件操作栏中新增显式的删除按钮（`.btn-delete-manuscript`），并在亮色/暗色模式下提供精致优雅的警示交互微动效；
   - 在手稿编辑模态框（Manuscript Modal）底部左侧新增危险操作删除按钮（`.btn-danger #btn-modal-delete-man`）；
   - 实现高可靠的 `deleteManuscript(manuscriptId)` 调度函数：支持智能计算受影响范围并在二次确认对话框中给出友好提示，级联调用底层 `storage.recordEntityDeletion` 安全剔除 manuscript 及其全部关联 submissions 并记录 tombstone 墓碑，执行 `storage.saveAll(db)` 持久化后同帧刷新全局看板、仪表盘与投稿详情面板。

2. **核心架构梳理与模块解耦优化**：
   - 优化前端各子模块的全局暴露与环境边界（`window.deleteManuscript` 与 `options.js` 装配总线），实现高内聚低耦合；
   - 规范宿主后端各系统职责边界（文献序列化、云端笔记同步、条目面板 Web Components 自愈、上下文菜单与桥接通信），强化防御性编程与只读模式保护。

3. **测试套件全面扩充与端到端验证**：
   - 新增 `tests/manuscript-deletion.test.js` 自动化测试套件，全面覆盖独立手稿安全删除、关联 submissions 级联Pruning与墓碑记录、取消确认时数据完整性无损保护；
   - 全量 106 项自动化单元测试 100% 满分通过。

4. **版本号统一收敛与打包校验**：
   - 依据工作区要求，统一 `manifest.json`、`docs/brand/product.json`、`chrome/content/preferences.xhtml`、`chrome/content/index.html`、`chrome/content/pages/options.html`、`chrome/content/scripts/options.js`、`chrome/content/scripts/index.js`、`update.json` 等全部 10 处版本标识至 `13.0.4`。
