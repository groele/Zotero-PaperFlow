# Zotero PaperFlow 15.0.1

Release Date: 2026-11-05
Compatibility: Zotero 10.0 - 12.* (Gecko 153+ Web Components)

## Review Deadline Improvements

- Add review-event fields for a revision deadline and major/minor revision decision.
- Preserve review deadlines after the review event is completed and show them in the dashboard and event manager.
- Keep R1/R2 review events synchronized with the submission revision deadline.
- Validate that a review event includes either a deadline or a major/minor decision.

Verification: `npm test` passed (134/134 unit tests; 8/8 package checks). The XPI payload and update feed were verified during `npm run build`.
