# Zotero PaperFlow 16.4.9

稿件卡片标题与期刊胶囊皇家钴蓝视觉强化版。针对弱对比度、色彩平淡问题进行全面视觉重构与色彩赋能，使管线卡片顶部序号徽标（`.submission-index`）与期刊名胶囊（`.journal`）获得鲜明、权威、层次分明的学术色彩表现力。

## 改进与视觉重构重点 (Fixed & Enhanced)

- **皇家钴蓝序号徽标 (`.submission-index`)**：
  - 彻底告别浅灰平淡质感，升级为经典皇家钴蓝渐变（`linear-gradient(135deg, #2563eb, #1d4ed8)`），边框 `#1d4ed8`，配合纯净白字 `#ffffff`（`font-size: 13.5px; font-weight: 700`）；
  - 规格保持小巧精致的 28px × 28px Squircle 方圆（`border-radius: 8px`），带有微光柔和投影（`0 2px 5px rgba(37, 99, 235, 0.28)`），醒目而不笨重；
  - 暗黑模式自动呈现温润通透的宝石蓝渐变（`linear-gradient(135deg, #3b82f6, #2563eb)`），边框 `rgba(96, 165, 250, 0.4)`，暗光下视觉识别度极高。
- **晶莹冰蓝期刊胶囊与宝石蓝指示点 (`.project-info .journal`)**：
  - 胶囊背景赋予通透纯净的冰蓝底色 `#eff6ff`，搭配精致淡蓝外框 `#bfdbfe`；
  - 期刊名字体采用深邃海军蓝 `#1d4ed8`（`font-weight: 700`），文字辨识度大幅飞跃；
  - 呼吸指示点升级为 6px 宝石蓝高亮圆点（`#2563eb`，外环微晕 `rgba(37, 99, 235, 0.22)`），在暗黑模式下呈现温和的天空蓝（`#60a5fa`），与整个卡片形成蓝底白字、深蓝文字与右侧橙色修回状态的完美多层次视觉韵律。
- **全链路测试与架构守卫 (Architecture & Test Integrity)**：
  - 所有 117 个 TypeScript 源码、46 个 CSS 样式表及测试套件恪守 360 行单文件红线（`debtCleared: true`）。
  - 全部 16 项架构守卫、153 项单元测试与打包自检 100% 绿色通过。
