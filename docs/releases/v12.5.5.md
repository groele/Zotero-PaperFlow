# Zotero PaperFlow 12.5.5

Released: 2026-10-24

- Freeze frontend save requests before normalization and asynchronous host or bridge calls.
- Preserve edits entered while a save is pending, rebasing independent changes on the committed snapshot without sharing the mutable editor object with the committed cache.
- Retain overlapping local/remote edits and the original conflict-detection revision. Report pending changes instead of a false saved state.
- Ignore older responses that would roll back a newer adopted revision. Defer database broadcasts while the current editor has pending changes.
- Add regression tests for delayed responses, nested-object isolation, record merging, normalization and message-bridge behavior, plus a real Gecko frontend persistence check.

All 65 JavaScript regressions and seven package regressions passed. In an isolated Windows Zotero 10.0.6 profile, ten native checks and one fresh-process restart check passed, including frontend saves through real IOUtils and a successful follow-up save of pending input. Main-profile installation and external sync services are outside this change.
