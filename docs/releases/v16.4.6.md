# Zotero PaperFlow 16.4.6

时间线事件管理器模块化色彩与科研节奏对齐版。彻底解除卡片完成状态对事件模块色彩的强制覆盖，让每一个学术里程碑卡片根据科研生命周期工作流节奏（实验/研究-海蓝、写作初稿-紫罗兰、投稿送审-温暖橙、修改修回-深绯红、接收出版-学术绿）渲染左侧精致指示条、微调柔和背景与边框，同时完整保留完成状态徽标与编辑操作键。

## 改进与修复重点 (Fixed & Improved)

- **时间线事件管理器色彩与科研节奏对齐 (Pipeline Rhythm & Module Color Harmony)**：
  - 修复此前所有节点在全部完成（如 `共 8 个节点 · 8 个已完成`）时，卡片背景、边框、左侧条和圆点被统一强制覆盖为全绿的单调问题。
  - 实现事件卡片按学术生命周期流水线模块严格映射语义色彩：
    - **研究与实验阶段** (`experiment_start`, `experiment_done`, `data_org`, `type-research`)：海蓝/青蓝色彩 (`#0891b2` / `#2563eb`)
    - **手稿写作阶段** (`draft_done`, `type-writing`)：紫罗兰/皇家紫色彩 (`#7c3aed`)
    - **投稿送审阶段** (`submit`, `r1_comments`, `r2_comments`, `type-submission`, `type-review`)：温暖橙/琥珀色彩 (`#f97316` / `#d97706`)
    - **修改修回阶段** (`r1_revised`, `r2_revised`, `type-revision`)：深绯红/珊瑚红色彩 (`#dc2626`)
    - **接收与录用阶段** (`accept`, `type-publication`)：翡翠绿色彩 (`#16a34a`)
    - **见刊与出版阶段** (`online`)：学术绿色彩 (`#059669`)
    - **拒稿** (`rejected`, `type-rejection`)：深红褐色 (`#b91c1c`)
- **卡片阶段色彩与完成状态徽标分层解耦 (Decoupled Stage Identity & Status Badge)**：
  - 将完成状态 (`completed` / `已完成`) 严格限定在节点标题旁的 `.timeline-event-status-badge`（清爽薄荷绿圆角胶囊），不再暴力覆盖卡片外框、指示条与主色调 `--event-color`。
  - 恢复卡片内 `.timeline-event-status-badge` 与 `.timeline-event-edit-pill`（「编辑」按钮）的优雅显示，卡片右侧通过浅色竖线分隔「×」删除按钮，与 v15.1/v16 系列交互保持无缝统一。
- **架构与质量守卫 (Architecture & Guard Integrity)**：
  - 全量 117 个 TypeScript 源码模块、46 个 CSS 样式表及所有测试脚本严格恪守 360 行单文件红线（`debtCleared: true`）。
  - 全部 16 项架构守卫、151 项单元测试、打包自检与标签自检 100% 绿色通过。
