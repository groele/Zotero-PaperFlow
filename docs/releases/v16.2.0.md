# Zotero PaperFlow 16.2.0

Zotero PaperFlow 正式发布 **16.2.0** 版本。本次升级聚焦于 CSS 样式架构领域化解耦、紧凑甘特图视图切换修复，以及主仪表盘高保真视觉打磨与学术科研质感跃升。

## 🌟 核心改进

### 1. 样式架构领域模块化拆分 (CSS Modularization)
- **解耦 6,051 行单体样式表**：将原庞大的 `options.css` 单体拆解为 6 个高内聚领域样式模块：
  - `chrome/content/styles/dashboard.css` (1,870 行)：统计 KPI 卡片、4 阶段周期汇总、4 栏关键事件轨与倒计时警报；
  - `chrome/content/styles/kanban.css` (281 行)：看板多泳道网格、平滑拖拽着陆动效与占位高亮；
  - `chrome/content/styles/submissions.css` (1,294 行)：手稿列表拆分视图、期刊投稿入口坞、快捷检索与多维筛选；
  - `chrome/content/styles/review-matrix.css` (661 行)：审稿意见三层结构、修回进度条与应答矩阵卡片；
  - `chrome/content/styles/modals.css` (528 行)：新建手稿/投审轮次弹窗、遮罩背景与表单控件；
  - `chrome/content/styles/zotero-drawer.css` (472 行)：Zotero 悬浮子窗口、实时条目检索与子笔记关联；
  - `chrome/content/styles/options.css` (507 行)：精简为控制台主容器框架、侧栏导航与模块加载入口。
- **并行加载加速**：在 `index.html` 与 `options.html` 中注入多 `<link rel="stylesheet">` 标签，实现浏览器原生多线程并行拉取与零闪烁极速渲染。

### 2. 紧凑/展开甘特图视图切换与偏好持久化 (Compact View Toggle & Persistence)
- **修复视图切换按钮失效**：全面排查并修复 `#btn-pipeline-view-toggle` 点击事件监听机制，确保视图切换与 `#dashboard-gantt.expanded` 样式正确联动；
- **状态持久化**：联动更新紧凑/展开图标与文案，并通过 `RFPlatform.storage.local` 跨会话存储用户视图偏好，保证再次打开时保持上次选定视图；
- **多端通信兼容**：原生支持直接 DOM 操作与 Bridge 消息通道双向同步。

### 3. 主页面高保真视觉打磨与科研质感跃升 (Dashboard Aesthetics Elevation)
- **KPI 统计卡片质感升级**：
  - 顶置 4 色渐变高亮饰条（在审蓝 `#3b82f6`、修回橙 `#f59e0b`、录用绿 `#10b981`、草稿紫 `#8b5cf6`）；
  - 升级 34px 等宽大数字（`tabular-nums`），悬停平滑上浮与细腻激活光晕；
- **4 大阶段周期统计区升级**：
  - 采用 4 种语义色卡（准备耗时、在审周期、修回周期、录用到刊）；
  - 配备微立体卡片背景与柔和色块标记；
- **4 栏事件轨卡片优化**：
  - 左侧依投稿状态增加 4px 状态色彩指示竖线；
  - 引入现代圆角矩形 `#序号` 徽章，芯片化（Chip）元数据标签；
  - 紧迫修回窗口激活呼吸脉冲微光辉，提醒时效节点；
- **自适应布局修复**：
  - 修复多分辨率下的水平 4 栏响应式网格布局，杜绝换行塌陷与纵向拉伸变形。

### 4. 架构合规与全链路版本一致性 (Zero-Drift & 360-Line Guard)
- **零债务代码规范**：全仓 45 个 TypeScript 模块严格恪守 $\le 360$ 行硬约束，`architecture-baseline.json` 保持 `debtCleared: true`（0 债务）；
- **全绿测试覆盖**：
  - 135/135 项单元测试 100% 通过；
  - 13/13 项架构守卫规则 100% 绿色通过；
  - 8 项打包自检测试及 Tag 语义校验 100% 通过；
- **现代平台契约**：严格对齐 Zotero 10.0 ~ 12.*，全面兼容 Gecko 153+ 标准。
