# Zotero PaperFlow 13.0.3

发布日期：2026-11-02。本版本为核心稳定性与自愈防护增强版本（Core Stability & Resilience Release），全面补全全局数据持久化事件监听，深度强化全模块 DOM 元素与事件注册的防御性编程，并提供完善的数据结构安全回退。

## 核心修复与改进

1. **补全 `setupSaveErrorListener` 全局保存状态监听器**：
   - 修复在 `DOMContentLoaded` 初始化阶段调用未定义函数 `setupSaveErrorListener()` 导致初始化后续事件绑定及工作区就绪事件 (`researchflow-workspace-ready`) 被阻断的隐蔽缺陷；
   - 在 `modules/dashboard-view.js` 中完整实现 `setupSaveErrorListener()`，实时监听 `researchflow-save-state` 事件并在保存失败或等待时向用户反馈全局 Toast 提示。

2. **DOM 查询与事件监听全面强化防御性编程**：
   - 全面改写 `modules/settings-view.js`、`modules/submissions-view.js` 和 `modules/kanban-view.js` 中的顶层及视图内事件监听，采用可选链（Optional Chaining `?.addEventListener`），杜绝由于个别控件未就绪或在非标准页面嵌入时抛出 `TypeError: Cannot read properties of null`；
   - 深度防御 `setupSubmissionSearch()` 与 `applySubmissionSearch()`，对所有搜索框输入框与计数 DOM 元素添加空值守卫与防重复绑定标记；
   - 在 `renderSubmissionDetails()` 中对 `db.projects` 与 `db.researchRecords` 补充空值数组回退（`|| []`），防止历史或精简数据库中因缺失字段抛出 `TypeError: Cannot read properties of undefined (reading 'find')`。

3. **测试套件全面扩充与端到端深度验证**：
   - 扩充 `tests/dashboard-render.test.js` 测试套件，新增看板渲染 (`renderKanban`)、投稿列表渲染 (`renderSubmissions`)、保存监听器挂载 (`setupSaveErrorListener`) 以及全套防御性搜索与监听函数安全执行测试用例；
   - 全量 103 项自动化单元测试 100% 满分通过。

4. **版本号统一收敛**：
   - 统一 `manifest.json`、`product.json`、`preferences.xhtml`、`index.html`、`options.html`、`options.js`、`index.js`、`update.json` 全平台版本标识至 `13.0.3`。
