# Zotero PaperFlow 15.0.3

Release Date: 2026-11-05
Compatibility: Zotero 10.0 - 12.* (Gecko 153+ Web Components)

## Inline Review Event Editor Redesign

- Rebuild the inline event editor into three clear areas: event details, schedule/review outcome, and notes/actions.
- Add visible labels for every control, including event date, review deadline, and review decision.
- Use stable grid columns, consistent spacing, right-aligned actions, and responsive single-column fallback for narrow windows.
- Preserve review-only deadline and decision behavior while making the controls discoverable and easier to manage.

Verification: `npm test` and `npm run build` passed. The packaged XPI, SHA-256 checksum, and update feed are generated during release verification.
