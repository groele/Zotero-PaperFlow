# Zotero PaperFlow 16.5.0

稿件卡片标题与期刊胶囊数字序号尺寸增强版。针对管线卡片序号辨识度与视觉聚焦，全面放大序号徽标（`.submission-index`）尺寸并增强数字排版，打造更大、更醒目、层次分明的学术视觉焦点。

## 改进与视觉增强重点 (Enhanced)

- **数字序号徽标尺寸全面放大 (`.submission-index`)**：
  - 徽标规格从 28px 提升至 34px（`min-width: 34px; height: 34px; padding: 0 8px; border-radius: 9px`），支持单双位数自适应扩展；
  - 数字字号由 13.5px 放大至 **16px**，字重强化至 **800 极粗字重**，选用 Tabular 等宽数字排版，无论远近浏览均清晰醒目；
  - 保留经典皇家钴蓝渐变底色与细腻投影，视觉存在感大幅提升，数字更饱满有力。
- **期刊胶囊与呼吸指示点黄金比例协同 (`.project-info .journal`)**：
  - 期刊胶囊高度同步优化为 32px（`min-height: 32px; height: 32px; font-size: 14px; line-height: 30px`），与放大后的 34px 序号徽标形成平齐和谐的视觉线；
  - 呼吸指示点升级为 6.5px 宝石蓝活跃圆点，搭配冰蓝底色 `#eff6ff` 与海军蓝字 `#1d4ed8`，卡片头部层次丰富、专业典雅。
- **全链路测试与架构守卫 (Architecture & Test Integrity)**：
  - 所有 117 个 TypeScript 源码、46 个 CSS 样式表及测试套件恪守 360 行单文件红线（`debtCleared: true`）。
  - 全部 16 项架构守卫、153 项单元测试与打包自检 100% 绿色通过。
