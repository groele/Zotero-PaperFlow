# Zotero PaperFlow 16.3.0

Zotero PaperFlow 正式发布 **16.3.0** 版本。本次升级聚焦于主仪表盘核心功能全量复现、标的序号与期刊名视觉强调、顶部 KPI 统计计数动态恢复，以及投稿历程分享按钮在各种布局下的稳定呈现。

## 🌟 核心改进

### 1. 标的序号与期刊名视觉层级显著加大 (Enhanced Visual Hierarchy)
- **标的序号徽章（`.submission-index`）升级**：
  - 尺寸增大至 `32×32px`，字号提升至 `14.5px` 特粗体（`font-weight: 800`，`tabular-nums` 等宽对齐）；
  - 配备立体微渐变背景（`linear-gradient(135deg, rgba(99,102,241,0.16), rgba(79,70,229,0.08))`）与柔和光晕投影，在明暗主题下均极为清晰；
- **目标期刊标签（`.journal`）层级强化**：
  - 字号提升至 `14px` 粗体（`font-weight: 750`），32px 高度圆角胶囊药丸；
  - 配备清晰的学术期刊标志性彩点与通透边框，与文献标题形成鲜明的视觉梯次，一眼辨识投稿阵地。

### 2. 顶部 3 大 KPI 统计计数全量复现 (KPI Metric Counters Restoration)
- **动态计数修复**：彻底修复 `renderDashboard()` 遗漏更新 `#stat-accepted-submissions`、`#stat-active-submissions` 与 `#stat-total-submissions` 的问题，精准计算并实时呈现已接收发表、在审与总投稿计数；
- **交互筛选联动**：为三张统计卡片绑定规范的 `data-filter`（`accepted` / `active` / `all`），点击可无缝筛选下方甘特图时间线，并同步更新卡片的选中激活态与 `aria-pressed` 属性。

### 3. 条目分享与操作按钮全量显式呈现 (Zero-Clipping Share & Action Buttons)
- **双重分享入口保障**：
  1. **标题行常驻快捷分享**：在第一栏顶部标题行（期刊名与状态标签右侧）新增常驻高可见度的 **「📤 分享历程」** 快捷按钮，无论处于展开还是收起模式均一眼可见；
  2. **底部操作栏显式保障**：排查并彻底移除了外层卡片与内容区的 `overflow: hidden` 裁剪陷阱，确保底部操作条（`详情`、`+ 事件`、`管理事件`、`📤 分享历程`）100% 完整平铺，不再被边界截断；
- **事件监听完整绑定**：采用 `querySelectorAll` 全量绑定所有分享入口，点击即刻呼出 Share Studio 投稿历程生成器。

### 4. 时间线警报与全生命周期交互赋能 (Interactive Alerts & Workflow Navigation)
- **时间线警报点击直达**：为待办事件条目注入鼠标手势与点击事件，点击警报项可直接呼出对应的事件编辑抽屉；
- **修回日历一键导出**：警报卡片右上角 `📅 .ics` 按钮可一键导出所有活跃稿件的修回截止日历，单个条目也可单独导出专属日历订阅；
- **紧凑/展开甘特图自由切换**：右上角切换按钮（`Compact` / `Expanded`）支持本地持久化记录，切换状态即时生效且跨会话保持。

### 5. 架构合规与全链路版本一致性 (Zero-Drift & 360-Line Guard)
- **零债务代码规范**：全仓 112 个 TypeScript 源码文件严格恪守 $\le 360$ 行硬约束，`architecture-baseline.json` 保持 `debtCleared: true`（0 债务）；
- **全绿测试覆盖**：
  - 136/136 项单元测试 100% 通过；
  - 13/13 项架构守卫规则 100% 绿色通过；
  - 8 项打包自检测试及 Tag 语义校验 100% 通过；
- **现代平台契约**：严格对齐 Zotero 10.0 ~ 12.*，全面兼容 Gecko 153+ 标准。
