# Zotero PaperFlow 13.6.0

发布日期：2026-11-03。本版本为模块化设置架构、全量功能开关治理与公开命名空间对齐发布版（Modular Settings Architecture & Full Feature Switch Governance Release），彻底重构 Zotero 设置面板为清晰自洽的五大业务流转模块、全量补齐22项核心功能的细粒度独立开关、对齐 `Zotero.PaperFlow` 公开命名空间与 `PaperFlow/*` 现代标签标准、实现防标签污染保护与阅读器划词菜单开关联动；面向 Zotero 10+ 现代 Web Components 架构（10.0–12.*）。

## 核心改进与特性

1. **设置面板模块化架构重构 (`preferences.xhtml`, `preferences.css`, `preferences.js`)**：
   - 彻底破除过去功能开关堆叠分散、层级不明的弊端，遵循 `AGENTS.md` §4.2 卡片容器基准网格与三级层级体系（`16px` 外边距、`40px` 黄金对齐基准线、`margin-inline-start: 24px` 严格对齐）；
   - 按论文处理全生命周期自上而下抽象划分为五大高内聚模块：
     - **模块 1：界面交互与窗口唤起 (`#rf-acc-window`)**：工作台窗口模式（主窗口标签页、独立窗口、轻量级浮窗）、浮窗置顶与快速入口管理；
     - **模块 2：Zotero 宿主与文献库深度集成 (`#rf-acc-integration`)**：条目右键菜单联动、阅读器划词摘录菜单开关、条目信息窗格看板开关、条目状态标签自动同步开关；
     - **模块 3：写作看板与审稿回复工作流 (`#rf-acc-workflow`)**：空阶段折叠、期刊投稿门户快捷链接、默认审稿修回导出格式（LaTeX / Markdown / Word HTML / Response Matrix）；
     - **模块 4：数据存储、多云同步与灾备韧性 (`#rf-acc-data`)**：存储引擎状态、外部配置导入策略（安全合并 / 覆盖恢复）、GitHub 云端同步凭证与 WebDAV 同步服务；
     - **模块 5：版本信息与运行诊断 (`#rf-acc-about`)**：版本徽标、官方安装包链接、开源仓库入口与一键导出运行诊断报告功能。

2. **全量 22 项功能细粒度开关治理与默认值补齐 (`prefs.js`, `index.js`)**：
   - 全面梳理并对齐全部 22 项功能在设置面板与运行时的对应关系，在 `prefs.js` 中补齐默认声明：
     - `enableReaderIntegration`（默认 `true`）：控制是否在 Zotero PDF/EPUB 阅读器中注入划词摘录右键菜单；
     - `syncStatusTags`（默认 `false`）：**标签防污染保护**，只有用户明确启用时才向文献条目写入状态标签；
     - `showJournalPortals`（默认 `true`）：控制是否在投稿详情中展示期刊系统官网直达按钮；
     - `collapseEmptyKanbanStages`（默认 `false`）：控制是否在看板中自动折叠无手稿的空白阶段；
     - `defaultRebuttalExportFormat`（默认 `'latex'`）：设置修回信与 Cover Letter 的默认首选导出模板；
     - `importMode`（默认 `'merge'`）：控制从外部 JSON 导入数据时的合并/覆盖防护策略。

3. **代码标识与公开命名空间标准对齐 (`index.js`, `preferences.js`)**：
   - 确立 `Zotero.PaperFlow` 为全局公开访问入口，保持 `Zotero.PaperFlow === Zotero.ResearchFlow` 双向完全等价；
   - 状态标签标准升级为 `PaperFlow/01-选题大纲` ~ `PaperFlow/07-已正式发表`，同时清理阶段兼容识别历史 `ResearchFlow/*` 与 `RF/*` 标签；
   - 论文管线分类集合默认名称更新为 `🚀 Zotero PaperFlow 论文管线`，并自动识别复用已有的 `🚀 ResearchFlow 论文管线`。

4. **开关联动自愈与无缝热更新 (`index.js`)**：
   - 建立 `initPrefObserver` 深度监听，当用户在设置面板切换 `enableReaderIntegration`、`showContextMenu`、`enableItemPane` 时，自动调用 `updateReaderContextMenu()`、`updateItemContextMenu()` 与 `updateItemPaneSection()` 进行动态注册与注销，无需重启宿主即时生效。
