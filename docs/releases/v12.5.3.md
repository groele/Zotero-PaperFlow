# Zotero PaperFlow 12.5.3

Released: 2026-10-24

## Fixed

- Enforce revision-safe saves so an older window or stale asynchronous operation cannot silently overwrite newer committed data.
- Preserve the existing add-on identity, preferences, database names, import behavior, and update-feed compatibility.

## Install

Install `zotero-paperflow-12.5.3.xpi` through Zotero's add-on manager. Do not install the GitHub source archive.

## Verification and limits

- The revision-safe storage test suite and repository package checks were run for this release.
- The XPI archive was rebuilt from the reviewed source and checked for a valid ZIP, matching manifest version, and update-feed consistency.
- Native Zotero acceptance and all external sync providers were not revalidated in this release unless explicitly listed in the final release verification record.
