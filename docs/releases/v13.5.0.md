# Zotero PaperFlow 13.5.0

发布日期：2026-11-03。本版本为审稿修回完结统计、多轮转投子笔记智能同步与全仓库防漂移增强版（Rebuttal Progress & Multi-Round Child Note Sync Release），完善审稿意见「辩明无改动」状态的修回进度计算、强化多轮转投场景下 Zotero 子笔记的活跃轮次自动遴选与审稿状态徽标渲染、严格对齐设置页三级层级字重与缩进规范，并在打包校验链路中新增中英文 README 与渲染版本防漂移验证。

## 核心修复与改进

1. **审稿修回进度统计优化 (`renderRebuttalProgressTracker`)**：
   - 将 `clarified`（「辩明解释 / 无需正文改动」）状态与 `addressed`（「已答复完成」）一并纳入修回完结百分比（`resolved = addressed + clarified`）与各审稿人完成度分片（`stat.done/stat.total`）；
   - 当存在辩明条目时，在进度卡片底部独立展示「💬 已辩明 / Clarified」计数，确保含辩明解释的修回轮次能够准确达成 `100% Completed`。

2. **Zotero 子笔记多轮转投智能同步与审稿状态徽标增强 (`syncManuscriptToChildNote`)**：
   - 修复多轮投稿（如拒稿转投后存在多个关联 `submissions`）同步子笔记时固定读取首条历史记录的问题，对齐 `RFCore.getCurrentSubmission` 逻辑优先遴选最新非前驱活跃轮次；
   - 目标期刊名称优先读取当前活跃投稿轮次的 `targetJournal` / `journalName`，再回退至手稿预设目标期刊；
   - 里程碑时间轴同步兼容现代节点字段（`completeDate`、`planDate`、`dueDate`、`status === 'completed'`）与旧版字段（`date`、`completed`）；
   - 在同步生成的 Zotero 子笔记「审稿人逐条意见与修回回复矩阵」表格中新增解决状态彩色徽标（`✔ 已答复` / `💬 已辩明` / `⏳ 处理中` / `⭕ 待处理`）。

3. **设置面板三级层级与排版规范精调 (`preferences.css`, `preferences.js`, `preferences.xhtml`)**：
   - 严格遵循工作区 `AGENTS.md` §4.2 三级层级规范，将二级主复选框标题 `.rf-check-title` 字重调整为标准 `400`（常规），移除下拉选择框从属说明的内联 `margin` 覆盖，保持 `40px` 黄金对齐基准线；
   - 清理 `chrome/content/scripts/preferences.js` 与 `chrome/content/scripts/index.js` 中的历史回退版本号硬编码，统一更新至 `13.5.0`。

4. **全仓库版本防漂移校验与文档同步 (`release_package.py`, `README.md`, `README.en.md`)**：
   - 同步更新 `README.md` 与 `README.en.md` 的顶部版本说明、徽标、XPI 下载链接与兼容性矩阵至 `13.5.0`；
   - 在 `scripts/release_package.py` 与 `tests/readonly-guard.test.js` 中新增对 `package.json`、`chrome/content/scripts/options.js`、`README.md`、`README.en.md` 的强制版本一致性断言，杜绝文档与安装包版本漂移。
